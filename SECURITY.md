# Security policy

Please report security issues with the Assetfy MCP server (`https://mcp.assetfy.com/mcp`), its OAuth flow or the plugins in this repository privately to **hallo@assetfy.com** with the subject "Security". Do not open a public issue.

Include what you found, how to reproduce it and the impact you expect. We will get back to you and keep you informed until the issue is resolved.
